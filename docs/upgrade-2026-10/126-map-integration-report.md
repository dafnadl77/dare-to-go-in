## המסלול החדש

חלום (כתיבה או הקלטה, עם התמלול החי, בלי שינוי) ← ניתוח (קרדיט אחד, בלי שינוי) ← תמונה ← כניסה לחלום ← תחושות ← **מפת הרגעים** ← שיחה בכל רגע ← **המבט השלם על החלום** ← "להמשיך" ← לשמור או לשחרר ← הארכיון.

**בשיחה, בכל רגע:**
- הרגעים נפתחים בכל סדר;
- עד 3 שאלות לרגע, ואחריהן משפט סיום;
- שלושת כפתורי הכיוון;
- שתי אפשרויות הסיום.
