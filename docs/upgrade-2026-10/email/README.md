# מייל אימות כתובת: תבנית חדשה (מוכנה, לא פעילה)

הקובץ: `confirm-signup.html` (תבנית Supabase "Confirm signup"). תצוגה מקדימה: `preview-desktop-mobile.png`.

## מה בתבנית
- **פונטים של האתר:** Heebo (גוף, כותרות, כפתור; 400, 500, 700) ו־Fraunces 400 (שם המותג בלבד, כמו באתר). נטענים דרך Google Fonts בלקוחות שתומכים (Apple Mail, iOS), ובשאר הלקוחות יש גיבוי: Heebo ← Assistant ← Arial ← Helvetica Neue; Fraunces ← Georgia ← Times New Roman.
- **צבעים מהאתר:** `#060706` (שחור לילה), `#f4f0e8` (שנהב, הכרטיס), `#3c3627` (טקסט), `#8f8672` (כיתוב משני). גוון רקע ודפדפן בהיר נגזר מהם (`#e8e2d4`, `#ece6d8`).
- **מבנה:** פס מותג כהה עם שם המותג, תמונת הקשת הלילית מהאתר, כרטיס שנהב עם כותרת, טקסט, כפתור כהה עגול, תיבת "לא נרשמתם", קישור חלופי, וקישורי תנאים, פרטיות וביטולים. בלי קישורי רשתות חברתיות.
- **טכני:** טבלאות וסגנון inline, בלי תמונות רקע, `color-scheme: light only`, תצוגה רספונסיבית (ברייקפוינט 620px), תמונה כתג `img` עם `alt`, וטקסט מקדים (preheader).
- **משתנים:** נשמר `{{ .ConfirmationURL }}` בלבד (כפתור וקישור חלופי). לא שונו כתובת האישור, התוקף או הלוגיקה.

## מגבלה: שפה אחת לכל מייל
Supabase מחזיק תבנית אחת לכל סוג מייל, וההרשמה בקוד לא שולחת את שפת המשתמש, ולכן **המייל דו־לשוני**: עברית (מימין לשמאל) למעלה, אנגלית (שמאל לימין) מתחת, באותו עיצוב. מייל בשפה אחת בלבד דורש שינוי קטן בקוד ההרשמה (להעביר `language` כנתון משתמש), ולא בוצע כי ביקשת לא לשנות את הלוגיקה.

## שלבי ההפעלה (ב־Supabase, אצלך, כ־3 דקות)
1. **גיבוי:** Supabase ← הפרויקט  ← Authentication ← Emails (Email Templates) ← **Confirm sign up**. מסמנים את כל תוכן השדה (Ctrl+A), מעתיקים, ושומרים בקובץ  (אפשר לשלוח לי ואשמור בתיקייה). רושמים גם את הנושא (Subject) הנוכחי.
2. **נושא:** מחליפים ל־.
3. **גוף:** מוחקים את התוכן ומדביקים את כל . ודאי ש־ מופיע בדיוק כפי שהוא (4 פעמים) ולחיצה על Save.
4. **לא נוגעים** בשאר ההגדרות: Site URL, Redirect URLs, תוקף הקישור, וגם לא בתבניות Magic link, Reset password ו־Invite.
5. **בדיקה:** הרשמה בכתובת מייל שבשליטתך (נוצר חשבון בדיקה אמיתי, אפשר למחוק אחר כך). בודקים: המייל הגיע, העיצוב נכון, הכפתור מאשר את הכתובת ומחזיר לאתר, והקישור החלופי עובד. אם משהו שבור: חוזרים לגיבוי מסעיף 1 ולוחצים Save.
